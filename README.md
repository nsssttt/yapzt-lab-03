# Lab 03 - Alloy Models

The Alloy models cover a constrained car model, a library with borrowing limits, and a computer network with directed channels. PlantUML diagrams show representative instances and counterexamples.

## Use the Alloy models

Open `task1_corrected.als`, `library_extended.als`, or `computer_network_v5.als` in Alloy Analyzer 6.2. Use **Execute** to run a `run` command and **Check** to evaluate an assertion. `task1_counterexample.als` preserves the starter model used to demonstrate the whitespace counterexample.

## Render the diagrams

With PlantUML installed, render the diagram sources from this directory:

```sh
plantuml -tsvg *.puml
```
